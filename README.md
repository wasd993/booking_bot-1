## Быстрый старт

### 1. Клонировать / распаковать проект

```bash
cd booking_bot
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate        # Linux / macOS
# venv\Scripts\activate         # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить `.env`

```bash
cp .env.example .env
nano .env            # или любой редактор
```

Заполните:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot))
- `STARS_PRICE` — стоимость записи в Stars (целое число ≥ 1)

### 5. Запустить

```bash
python main.py
```

## Telegram Stars — как это работает

```
Клиент нажимает "Записаться"
        ↓
Выбирает дату и время (слот временно резервируется)
        ↓
Бот отправляет invoice (currency=XTR, provider_token="")
        ↓
Telegram показывает нативный экран оплаты
        ↓
pre_checkout_query → бот проверяет запись → отвечает ok
        ↓
successful_payment → запись становится active, charge_id сохраняется
        ↓
При отмене: bot.refund_star_payment(user_id, charge_id)
```

- `XTR` — внутренний код валюты Telegram Stars
- `provider_token=""` — обязателен (пустая строка для Stars)
- Возврат работает **только если отмена выполнена более чем за 12 часов до записи** и в рамках 30 дней с момента оплаты
- Незавершённые `pending`-записи старше 30 минут освобождают слот автоматически

## Деплой на VPS / Railway / Heroku

### Systemd (VPS)

```ini

[Unit]
Description=Booking Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/booking_bot
ExecStart=/opt/booking_bot/venv/bin/python main.py
Restart=always

[Install]
```


Добавьте переменные окружения из `.env.example` в настройках проекта и запустите:

```

```

## FAQ

**Q: Бот не отвечает на `/start`**
A: Проверьте `BOT_TOKEN` в `.env`. Убедитесь, что бот не запущен в двух экземплярах одновременно.

**Q: Платёж проходит, но запись не подтверждается**
A: Убедитесь, что хэндлер `payments.router` включён **первым** в `dp.include_routers(...)`.

**Q: Возврат Stars не работает**
A: Возврат доступен только в течение 30 дней. Проверьте, что `charge_id` сохранился в БД — поле `charge_id` в таблице `appointments`.

**Q: Слот занят, но записи нет**
A: Pending-записи старше 30 минут считаются истёкшими. Проверьте, не завис ли процесс оплаты у пользователя.

**Q: Как добавить несколько администраторов?**
A: В `.env` укажите ID через запятую: `ADMIN_IDS=111,222,333`.

**Q: Где хранятся данные?**
A: В файле `bot.db` (SQLite) в корне проекта. Для бэкапа достаточно скопировать этот файл.
